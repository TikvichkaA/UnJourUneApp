1. Sources prioritaires à intégrer (fiables, structurantes)
🗞️ Presse d’investigation & data-journalisme

À privilégier car sourcées, factuelles, et souvent déjà hiérarchisées.

StreetPress (municipales, extrême droite, élus locaux)

Basta! (cartographies, dossiers municipaux)

Mediapart (sections politique locale, enquêtes)

Les Jours (obsessions RN, élus, réseaux)

Disclose (plus rare localement, mais très qualitatif)

👉 Méthode :
Scraping par dossiers ou tags, pas par homepage.

🏛️ Sources institutionnelles / administratives

Utile pour fiabiliser les données “neutres”.

Ministère de l’Intérieur – résultats électoraux passés

data.gouv.fr :

résultats municipales 2014 / 2020

données INSEE (population, CSP, âge)

Sites officiels des mairies (pages “Le Maire”, “Conseil municipal”)

👉 Méthode :
API ou CSV quand possible, scraping HTML en dernier recours.

🌐 Réseaux sociaux (à manier avec précaution)

Pas pour “prouver”, mais pour détecter.

Facebook (pages officielles de candidats / listes)

X / Twitter (anciens tweets, citations)

YouTube (meetings, interviews locales)

👉 Méthode :

scraping descriptions, bios, posts épinglés

jamais d’analyse hors contexte → toujours lier à une source publique

3. Normalisation & dédoublonnage (clé pour éviter le chaos)
Identifiants forts

Commune : code_insee

Candidat : nom_normalisé + commune_id

Dinguerie : hash(citation + auteur + source)

Normalisation minimale à automatiser

Noms propres (majuscules / accents)

Partis (RN, Reconquête, UDR → enum)

Dates (ISO 8601)

Citations : toujours texte exact + source

👉 Claude Code doit refuser toute insertion sans source.
